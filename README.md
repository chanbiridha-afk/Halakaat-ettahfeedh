# متابعة مسار الحفظ

تطبيق ويب ثابت (HTML/CSS/JS) بلا خادم ولا أدوات بناء، يعمل كتطبيق PWA ويُثبَّت على الهاتف.
البيانات تُحفظ في متصفح الجهاز (localStorage)، ويمكن نقلها من تبويب «نسخ واستيراد».

## النشر على GitHub
1. أنشئ مستودعًا جديدًا وارفع محتوى هذا المجلد إلى جذره.
2. لـ GitHub Pages: Settings ← Pages ← Source: Deploy from a branch ← main ← /(root).

## النشر على Netlify
- من لوحة Netlify: Add new site ← Import an existing project واختر المستودع (اترك أمر البناء فارغًا، فملف netlify.toml يحدد النشر من الجذر).
- أو بلا مستودع: اسحب المجلد إلى Netlify Drop.

## ملاحظات
- عند تعديل الملفات غيّر رقم الإصدار V في sw.js ليصل التحديث للمستخدمين.
- بيانات كل جهاز ونطاق منفصلة؛ استخدم النسخ الاحتياطي عند تغيير النطاق.
